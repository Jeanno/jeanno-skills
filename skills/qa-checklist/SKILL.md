# QA Checklist

Generate a fast, actionable manual verification checklist for the user before concluding work:

1. **Navigation / Setup**: exact steps, screen path, or seed data needed to reach the state.
2. **Key behaviors to verify**: expected layout, animation timing/easing, transitions, and gesture responses.
3. **Edge cases**: light/dark mode, screen rotation, rapid interactions, or empty/error states.

*Keep it actionable and bulleted so the user can verify in under 60 seconds.*
