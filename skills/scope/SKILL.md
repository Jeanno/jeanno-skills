# Scope

- Step 1: Run `/jeanno-skills:align`. Then record decisions and out-of-scope items to the issue body
- Step 2: Break down to smaller stages (sub-issues). Each stage the system gains a small capability and easily verifiable.
- Step 3: If needed, decompose each stage into sub-issues
  **Propose & file**: get user approval, then create sub-issues in dependency order.
