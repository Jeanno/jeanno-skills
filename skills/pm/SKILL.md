# PM

- **Phase 1 — Scope**: run `/scope` to settle roadmap and strategy decisions, and decompose.
- **Phase 2 — Execute**: spawn an agent team, coordinate work, and prompt user for new decisions only when blocked.
- **Phase 3 - Code Quality**: run `/simplify`, then `/code-review` to fix the reported problems. Finally run /crap and fix the reported problems.
- **Phase 4 - User QA: run /qa-checklist
